# レビュー記録

タスクごとのレビュー結果と、指摘をどう判断・反映したかを残します。

- ファイル名：`TASK-<ID>-review.md`
- 書く人：Claude Code の reviewer サブエージェント（PR 前）と、claude.ai プロジェクトの【レビュー】（PR 後）

## 書き方

```markdown
# TASK-<ID> レビュー記録

## 1回目（reviewer サブエージェント・YYYY-MM-DD）
| 重要度 | ファイル:行 | 指摘 | 判断 | 反映 |
|---|---|---|---|---|
| 高 | （例）src/xxx.ts:42 | 〇〇 | 直す | コミット abc1234 |
| 低 | … | … | 見送り（理由） | — |

## 2回目（claude.ai【レビュー】・YYYY-MM-DD・PR #番号）
…
```

「判断」欄に、直す・見送るの理由を書くことで、AI の指摘をうのみにせず自分で判断したことが残ります。
