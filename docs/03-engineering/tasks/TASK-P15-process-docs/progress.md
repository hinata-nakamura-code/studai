## 差分の要約（rules.md・CLAUDE.md）

- rules.md「1. 役割」：PM だけが書く Notion に「工程別ドキュメント」を足した
- rules.md「5-1」手順7：マージ前にそのタスクの PR にコミットするものを、レビュー記録と「progress.md のステータスと完了報告の『状態』を『✅ 完了（PR #番号 で develop にマージ済み）』にした変更」の2つにした
- rules.md「5-2」：設計の資料（要件定義・基本設計・詳細設計）は、PM が Notion に書き、作者が承認してから PM がファイルにして置き、Claude Code にコミットを依頼する、を足した
- rules.md「7.」：冒頭を、工程ごとに正本を分ける表（設計は Notion、実装・テストはリポジトリ）に書き換えた。置き場所の表に、要件定義・基本設計・詳細設計・単体テスト・結合テストの5行を足した。箇条書きに、画面と ADR はファイルが正本、設計を直すときは Notion を直して承認後にファイルを出し直す、実装は承認済みのファイルに従い Notion と食い違ったら止めて PM に知らせる、を足した
- CLAUDE.md「仕様の優先順位」②：「作者が承認した要件定義・基本設計・詳細設計（レビューを通って develop に入ったファイル。基本設計には画面も含む）」にした
- CLAUDE.md「1タスクの進め方」手順9：レビュー記録に加えて、progress.md を完了にした変更もそのタスクの PR にコミットしてからマージする、にした（rules.md 5-1 と同じ内容）
- reviewer の指摘による追加：rules.md「1.」の PM の欄に詳細設計を足した。rules.md「5-1」手順3と CLAUDE.md 手順8に、PR を作ったらステータスと「状態」を「🔵 レビュー待ち（PR #番号）」にする、を足した
