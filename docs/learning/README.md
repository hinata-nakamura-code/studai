# 学習メモ

技術を理解したまとめを残す場所です。Studai では、技術的なことは作者が理解してから決める・進めます（[`rules.md` の「3. 理解してから進める」](../rules.md#3-理解してから進める)）。ここに置くメモは、その「理解した」ことの証跡になります。

## 書き方

- 1テーマ1ファイル。ファイル名は kebab-case（例：`aurora-data-api.md`）
- 書く人：作者・PM（解説を受けて、作者が自分の言葉でまとめる）
- 関係するタスクがあれば、TASK-ID を書く

## メモに入れること

- 何者か、なぜ必要か
- 他の選択肢との違い
- Studai でどう使うか
- 作者のまとめ（3行）
